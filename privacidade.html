Política de Privacidade do Kanban D&D

Última atualização: 14 de outubro de 2026

O Kanban D&D é uma ferramenta de uso pessoal de Jean Wink (D&D Tráfego Pago). Esta política explica o que o app faz com os dados do Google quando o dono da conta autoriza o acesso.

Quais dados o app acessa

Só os eventos do Google Agenda da conta que autorizou o acesso, pela permissão calendar.events: título, data e hora, local, descrição, convidados, link do Google Meet, cor e lembretes. O app não acessa e-mail, contatos, arquivos nem outros dados da conta Google.

Para que os dados são usados

Para mostrar a agenda dentro do quadro de tarefas e para criar, editar ou excluir eventos quando o próprio usuário pede. Os dados não são usados para publicidade, não são vendidos e não são compartilhados com terceiros.

Onde os dados ficam

A autorização do Google fica guardada apenas nos computadores do dono do app, fora de qualquer repositório público. Uma cópia resumida da agenda (título, horário e link do Meet) fica no servidor privado do Kanban, protegido por senha, para mostrar a agenda quando o Google não responder.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

A autorização pode ser retirada a qualquer momento em myaccount.google.com/permissions ou pelo link "Desconectar" dentro do Kanban. Ao desconectar, a autorização guardada é apagada.
